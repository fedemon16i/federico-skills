# Federico Skills — Knowledge Center

**Federico Monroy's curated knowledge base for Product Intelligence, UX Research, Analytics and Design.**

This is not a collection of random notes.  
It is a structured, living knowledge system designed to be consumed by AI agents and by Federico with high signal and low noise.

---

## Purpose

When Federico faces a real problem (a new client, a product decision, a research need, a design challenge), this repository should answer:

> “What do I already know that is high-quality, current, and actionable?”

It reduces token waste, prevents inconsistent answers across models, and keeps domain knowledge consistent over time.

---

## How this repo is organized

| Path | What it contains |
|------|------------------|
| `/knowledge` | Curated domain knowledge (the core) |
| `/knowledge/research-methods` | Usability testing, interviews, contextual inquiry, rapid validation |
| `/knowledge/analytics` | Behavioral analytics frameworks, Pendo, Mixpanel, Hotjar patterns |
| `/knowledge/product-testing` | How to validate in 1 day, 2-3 days, 1 week |
| `/knowledge/design-systems` | Principles and practices |
| `/knowledge/interaction-design` | Motion, micro-interactions, HCI fundamentals |
| `/skills` | Reusable AI skills and prompts (execution layer) |
| `/templates` | Blank templates for consistency |

---

## Core principles

1. **Curation over collection** — Only high-signal knowledge stays.
2. **Living sources preferred** — Maze, Optimal Workshop, Qualtrics, Pendo, Usability.gov, IDEO, etc. over outdated books.
3. **Actionable** — Every document should help make a decision or execute better.
4. **Agent-ready** — Structure and language designed so any capable model can navigate and use it cleanly.
5. **STATUS.md first** — Any agent or human should start there.
