# Reference Products — Best-in-Class UX / Product

**Status:** Done · **Priority:** High  
**Use when:** Designing or critiquing UI — study **what these products do well**, don’t clone the brand.

Selection criteria: sustained user/product love, clear UX opinions, repeated citation in 2025–2026 design/product writing, and patterns Federico can reuse (tables, density, trust, nav, onboarding).

---

## How to use this catalog

1. Match **job** (issue tracking, money, admin table, marketing site) → pick 1–2 refs.  
2. Extract **principle** (speed, restraint, role flexibility) — not purple gradients.  
3. Apply inside the **client’s** DESIGN.md / existing DS.  
4. Pair with anti-slop + domain files so agents don’t paste “Linear clone.”

## Productivity & builder tools (high signal)

| Product | Steal this | Don’t steal blindly |
|---------|------------|---------------------|
| **Linear** | Keyboard-first, ⌘K, perceived speed, calm density, issue→action loop, onboarding to *aha* in few clicks | Bento-everywhere marketing layout as app UI |
| **Notion** | Progressive disclosure, empty→sample content, sidebar as workspace, flexibility + gentle guidance | Infinite customization as the default for ops tools |
| **Figma** | Multiplayer clarity, component systems, toolbars in context | Playful marketing color into enterprise admin |
| **Slack** | Channel mental model, search, progressive power features | Notification chaos |
| **Cursor / modern AI IDEs** | Intent in the flow of work; agent as multiplier | Chat-only for structured tasks |
| **Loom** | Outcome-first messaging; async clarity | Feature soup |
| **Vercel** | Developer trust via clarity + performance proof | Only works for dev audiences |
| **Supabase** | Sample project / realistic data to learn the product | — |
| **Calendly** | Extreme simplification of one job | Over-simplify multi-role enterprise |

**Shared practice:** design for the person who uses the product **daily**, not only the evaluator on day one. ⌘K is table stakes among power-user tools.

## Cross-cutting practices these products share

1. **Aha early** — sample data / first real action fast (Linear, Figma, Supabase).  
2. **Progressive power** — simple day one; depth later (Notion, Slack).  
3. **Search + command palette** when surface area grows.  
4. **Empty states with a path** — never a blank punishing dashboard.  
5. **Ship without breaking muscle memory** of power users (Linear ethos).  
6. **Role-appropriate defaults** in B2B (Salesforce-class thinking).  
7. **Trust through calm** in money and health-adjacent flows.
