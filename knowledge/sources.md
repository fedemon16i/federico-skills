# Preferred Living Sources

We prefer **current, maintained sources** over static books.

## Tier 1 — Primary (use first)

| Source | Why |
|--------|-----|
| Maze | Strong unmoderated testing + clear methodology docs |
| Optimal Workshop | Card sorting, tree testing, first-click, excellent explanations |
| Usability.gov | Classic but still solid foundational methods |
| Pendo | Behavioral analytics + feedback + guides (Federico already deep here) |
| Qualtrics | Surveys, XM, research rigor |
| Hotjar / Contentsquare | Session + behavior tools |
| Mixpanel | Event-based product analytics |

## Tier 2 — Strong secondary

| Source | Why |
|--------|-----|
| IDEO Design Kit | Human-centered methods (remote-friendly ones preferred) |
| Interaction Design Foundation | Conceptual depth (use selectively) |
| Nielsen Norman Group | Heuristics and research principles (filter for currency) |
| Microsoft / Google research guidelines | Enterprise-grade practices |

## Tier 3 — Reference only

- Older books on interview techniques or classic UX methods (use only when still accurate)
- Random Medium posts or unverified blogs

---

**Rule:** Prefer sources that are actively maintained and used in real product work in 2025-2026.
