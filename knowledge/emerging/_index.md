## Monthly review ritual (recommended)

Once a month:
1. Scan key sources for new methods, tools, or pattern shifts
2. Update or add documents in this section
3. Decide what moves from “emerging” into core knowledge
4. Note anything that should be pushed to `ai-capability-os` as a new capability

**Suggested sources to check monthly:**
- Maze, Optimal Workshop, Pendo blogs / changelogs
- Nielsen Norman Group (selectively)
- IDEO, Interaction Design Foundation (selectively)
- xAI / Anthropic / OpenAI design & agent writings
- Selected product teams doing agentic work in public
