# Portfolio Narrative: Ownership, Outcomes & Confidential Work

**Status:** Done · **Priority:** High  
**Source:** Interview feedback (Handl Health, Xplor prep, Aug 2026) + portfolio critique.

---

## The core problem (not skill — communication)

Interviewers often already believe Federico can **analyze complex problems and design**.  
What they cannot *see* without digging is:

> “He can **own** a product problem, move it through a team, and show a **measurable** result.”

So the portfolio reads as strong craft + research, weak **explicit ownership and outcomes**.

---

## What must be visible without asking

| Signal | How to show |
|--------|-------------|
| Ownership | “I owned X / shared Y / not responsible for Z” — not “I worked on” |
| Before → after | Problem → intervention → result (even without screenshots) |
| Decisions | 2–3 cards: decision, evidence, alternative, trade-off |
| Evidence | Research + behavioral analytics + what changed the plan |
| Collaboration | PM, eng, architecture — alignment, not solo hero |
| Outcome | Metrics, ranges, scale, or qualitative impact + confidentiality note |
| Reflection | What I would do differently |

---

## Case structure (verbal + page)

1. Context · 2. Users · 3. Problem · 4. **My ownership** · 5. Evidence · 6. Insight · 7. Options · 8. Decision · 9. Design · 10. Validation · 11. Outcome · 12. Reflection · 13. Interactive prototype **as evidence, not the story**

Opening line pattern: **“I owned…”** not “I worked on…”

---

## Confidential clients (e.g. EY)

- State confidentiality up front.
- No proprietary UI / exact metrics if forbidden.
- Substitute: flows sanitized, funnel stages, event taxonomy, decision matrices, research synthesis, scale (# workflows, teams, sessions).
- Animation/prototype = **supporting evidence**, not the narrative spine.

---

## Philosophy as evidence

Loop: Observe → Hypothesis → Design → Validate → Ship → Measure → Learn  
Line to keep: *If the numbers go against me, they’re not attacking me — they’re saying the solution doesn’t work.*
